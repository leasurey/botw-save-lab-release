# BOTW 存档实验室 · 正式发行版

《塞尔达传说：旷野之息》Wii U 1.5.0 离线存档编辑器。

本仓库提供**免安装 Windows EXE**：内置 Python 运行时，无需安装 Python、无需 Node.js、无需联网即可使用。

> 源码与构建脚本见上游仓库：[leasurey/botw-save-lab](https://github.com/leasurey/botw-save-lab)

当前版本：**V13.8**
目标平台：Wii U 1.5.0 日版 `game_data.sav`（signature 18203 / 0x471B）
界面语言：中文

---

## 功能

- savdata 旗标编辑
- 背包与物品编辑
- 马匹数据编辑
- 玩家位置编辑
- 挑战 / 任务数据编辑
- 存档完整性检查
- 写回前自动备份（.bak）
- 写回后自动回读校验

工作方式：终端程序负责读取、转换和写回 `game_data.sav`；内置网页编辑器负责可视化修改，全程无需联网。

---

## 快速开始

### 一、下载

在右侧 **Releases** 下载最新的 `botw-save-lab-v13.8-windows.zip`，解压到方便找到的位置。

解压后目录应如下（**整个文件夹保持在一起，不要单独把 exe 拖出来**）：

```
botw_lab\
├─ botw_lab.exe
├─ _internal\
├─ BotW-Save-Editor\
└─ editor\
```

> 与源码版不同：第三方转换器与字段表已随包内置，**无需你再自行准备**。

### 二、准备自己的存档

从 Cemu 或其他 Wii U 环境取得你的 `game_data.sav`，放到 `botw_lab.exe` 同一级：

```
botw_lab\
├─ game_data.sav    ← 你的存档
├─ botw_lab.exe
├─ editor\
└─ ...
```

> 修改前务必备份原始存档。

### 三、启动

双击 `botw_lab.exe`。

- 普通使用**不需要管理员权限**。
- 仅当存档位于受保护目录、写不进去时，才右键“以管理员身份运行”。

进入菜单后，第一次使用直接按回车，选 **[5] 完整流程** ⭐：

```
game_data.sav
      ↓
生成 JSON 数据
      ↓
打开网页编辑器
      ↓
修改存档
      ↓
导出修改后的 JSON
      ↓
返回终端
      ↓
写回 game_data.sav
      ↓
回读校验
```

---

## 菜单说明

| 按键 | 作用 |
|---|---|
| 回车 / 5 | 完整流程（推荐） |
| 1 | 仅 SAV → JSON |
| 2 | 仅 JSON → SAV 写回 |
| 3 / 4 / 6 | 单改旗标 / 背包 / 位置 |
| q | 退出 |

## 写回与安全机制

程序不会无条件覆盖存档：

- 每次写回前自动在 `backups\` 生成 `.bak` 备份。
- 覆盖前进行 SHA-256 校验，并要求你输入 `y` 明确确认。
- 若写回后发现问题，关闭 Cemu，把对应 `.bak` 重命名回 `game_data.sav` 即可恢复。

如要**彻底禁止覆盖原始存档**，可设置环境变量：

```
BOTW_NO_OVERWRITE_ORIG=1
```

## 常见问题

- **浏览器没自动打开**：终端会打印 `http://127.0.0.1:端口/...`，手动复制到浏览器即可。
- **提示没找到 .sav**：确认 `game_data.sav` 已放到 exe 同一级。
- **写回失败**：先关闭正在占用存档的 Cemu / 游戏。
