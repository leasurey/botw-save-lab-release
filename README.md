# BOTW 存档实验室 · 正式发行版

《塞尔达传说：旷野之息》Wii U 1.5.0 离线存档编辑器。

本仓库提供**免安装 Windows 文件夹版**：内置 Python 运行时，无需安装 Python、无需 Node.js、无需联网即可使用。

> 源码见上游仓库：[leasurey/botw-save-lab](https://github.com/leasurey/botw-save-lab)

当前版本：**V13.9**
目标平台：Wii U 1.5.0 日版 `game_data.sav`（signature 18203 / 0x471B）
界面语言：中文

---

## V13.9 更新

- **导出拆成两条通道**：`🎯 一键导出（自动写回）` 直接覆盖 `backups/<日期>/` 的四个 JSON，终端立刻能看到；
  各 `💾 导出 XXX` 按钮只做浏览器下载，页面会明确标注「已写回 / 已下载(未写回)」。
  **手动下载不再压制自动写回**（旧版会因此静默丢失修改）。
- **修复撤销**：纯背包会话里按钮不再一直灰着；马匹页撤销不再撤错对象；新增/删除/批量/染色/升星都纳入撤销栈。
- **修复显示**：护甲染色改完即时刷新；马匹亲密度 15% 不再显示成 0%；关闭页面不再误报未保存。
- **加固**：备份失败立即中止、写档原子替换、savdata 条数必须与原档一致；写回端点一次性令牌 + 同源校验。
- 字段表缺失时仍可导出（字段名退化为 `Unknown_<哈希>`，数值照常写回）。

完整变更见 [CHANGELOG.md](./CHANGELOG.md)。

## 功能

- savdata 旗标编辑
- 背包与物品编辑
- 马匹数据编辑
- 玩家位置编辑
- 挑战 / 任务数据编辑
- 存档完整性检查
- 写回前自动备份（.bak）
- 写回后自动回读校验

工作方式：终端程序负责读取、转换和写回 `game_data.sav`；内置网页编辑器负责可视化修改，全程无需联网。

## 快速开始

### 一、下载

在右侧 **Releases** 下载最新的 `botw-save-lab-v13.9-windows.zip`，解压到方便找到的位置。

解压后目录应如下（**整个文件夹保持在一起，不要单独把 exe 拖出来**）：

```text
BOTW存档实验室V13.9\
├─ botw_lab.exe
├─ _internal\
├─ BotW-Save-Editor\
├─ editor\
└─ 使用说明.txt
```

> 与源码版不同：第三方转换器与字段表已随包内置，**无需你再自行准备**。

### 二、准备自己的存档

从 Cemu 或其他 Wii U 环境取得你的 `game_data.sav`，放到 `botw_lab.exe` 同一级：

```text
BOTW存档实验室V13.9\
├─ game_data.sav    ← 你的存档
├─ botw_lab.exe
├─ editor\
└─ ...
```

> 修改前务必备份原始存档。

### 三、启动

双击 `botw_lab.exe`。

- 普通使用**不需要管理员权限**。
- 仅当存档位于受保护目录、写不进去时，才右键“以管理员身份运行”。

进入菜单后，第一次使用直接按回车，选 **[5] 完整流程** ⭐：

```text
game_data.sav
      ↓
生成 JSON 数据
      ↓
打开网页编辑器
      ↓
修改存档
      ↓
点「🎯 一键导出（自动写回）」
      ↓
返回终端
      ↓
写回 game_data.sav
      ↓
回读校验
```

## 导出方式（V13.9）

| 通道 | 入口 | 行为 |
|---|---|---|
| **① 自动写回**（推荐） | 顶栏 `🎯 一键导出（自动写回）` | 通过本地服务直接覆盖 `backups/<日期>/`，终端马上能检测到改动 |
| **② 手动导出** | 各 `💾 导出 XXX / 保存修改` 按钮 | 文件落到浏览器下载目录，需要自己搬运；页面会提示「终端看不到这份文件」 |

顶栏徽章显示当前处于哪条通道；每个文件标注 **✓已写回** / **↓已下载(未写回)**。

## 写回与安全机制

程序不会无条件覆盖存档：

- 每次写回前自动在 `backups\` 生成 `.bak` 备份；**备份失败即中止**，不会在没备份的情况下写活档。
- 覆盖前进行 SHA-256 校验，并要求你输入 `y` 明确确认。
- 写档采用「临时文件 + 原子替换」，中途断电不会留下写一半的存档。
- 若写回后发现问题，关闭 Cemu，把对应 `.bak` 重命名回 `game_data.sav` 即可恢复。

如要**彻底禁止覆盖原始存档**，可设置环境变量：

```text
BOTW_NO_OVERWRITE_ORIG=1
```

## 常见问题

- **浏览器没自动打开**：终端会打印 `http://127.0.0.1:端口/...`，手动复制到浏览器即可。
- **提示没找到 .sav**：确认 `game_data.sav` 已放到 exe 同一级。
- **写回失败**：先关闭正在占用存档的 Cemu / 游戏。
- **一键导出提示失败**：文件名不在白名单或目录不是 `backups/<日期>`；失败的文件会自动改为浏览器下载，按页面提示搬运即可。
- **想确认安装完整**：在文件夹里执行 `botw_lab.exe --selfcheck`，会打印解析到的编辑器/转换器路径并检查字段表。
